# Codex Local

This folder groups the local Codex files created for this project.

## Contents

- `AGENTS.md`: project-local operating model
- `.codex/skills/test-workflows-project-core`: local project-core skill
- `.codex/skills/bug-hunt-and-fix`: local bug workflow skill

## Important note

Codex discovers local project behavior from the operative files in:
- `AGENTS.md` at the repo root
- `.codex/skills/` at the repo root

For that reason, the same files are also kept in their operative locations.

This folder is the organized local bundle you asked for; the root copies are the ones Codex actually reads automatically.
